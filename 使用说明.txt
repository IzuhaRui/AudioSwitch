音频设备切换器（AudioSwitch）v1.6.4
==================================

（更简版：见同目录“使用说明-极简版.txt”）

【怎么启动】
  重要：不要从 AI 助手的对话界面里直接点击文件卡片“打开”本程序。
        那样程序会以 Windows 沙箱/低权限方式运行，Windows 不允许它创建
        任务栏图标，会直接弹提示退出。

  正确方式：
  1. 打开 Windows 的「文件资源管理器」；
  2. 打开下面这个文件夹：
     （就是本文件所在的文件夹）
  3. 双击 AudioSwitch.exe 运行。

  建议把整个文件夹放到固定位置（如 D:\Tools\AudioSwitch\），
  给 AudioSwitch.exe 创建桌面快捷方式，以后双击快捷方式即可。

【使用】
  1. 左键单击任务栏右下角的扬声器图标 -> 弹出设备面板。
  2. 面板分「输出」「输入」两组。当前默认设备的名称区和音量区会有
     底色高亮（浅色主题更深、深色主题更浅），右侧带 ✓，一眼可见。
  3. 单击设备名称行 -> 切换为系统默认设备。面板不会自动关闭，
     可以继续切换另一个设备（例如先切音响、再切麦克风）。
  4. 每个设备下方都有一条独立音量条：
       - 在音量条任意位置按下并拖动：调节该设备音量；
       - 拖动/播放时音量条上半部分会出现深色电平条，
         随当前播放/采集的声音大小实时跳动；
       - 音量条右侧数字显示当前音量（0~100）；
       - 单击左侧喇叭图标：一键静音 / 取消静音。
  5. 隐藏不用的设备：在设备名称上单击右键 ->「隐藏此设备」；
     隐藏选择会保存，重启后仍然隐藏。
     恢复所有设备：右键任务栏托盘图标 ->「取消所有隐藏」。
  6. 调节主输出音量后会播放 Windows 自带的提示音（“叮”）。
     不需要时：右键托盘图标 -> 取消勾选「音量调节提示音」。
  7. 关闭面板：再次单击托盘图标、按 Esc、或点击面板以外的任意位置。
  8. 应用音量：面板底部点「应用音量」-> 切换到单应用音量页，
     每个应用显示图标、独立音量条/静音按钮/电平表；可以在「返回设备」按钮切回。
     页面选择会被记住，下次打开直接回到上次页面。
  9. 右键单击托盘图标 -> 菜单：
     打开切换面板 / 刷新设备 / 声音设置 / 声音控制面板 /
     开机自动启动 / 音量调节提示音 / 取消所有隐藏 / 退出。

【任务栏图标】
  任务栏上的图标会实时显示当前主输出设备（音响）的音量状态：
    - 静音时显示“喇叭 + ×”；
    - 音量 0 / 低 / 中 / 高 分别显示 0~3 道声波；
    - 用键盘音量键、其他程序调音量或切换默认设备时会自动更新；
    - 鼠标悬停在图标上会显示当前设备名和音量百分比。
  所有图标（包括任务栏图标）均由矢量字形绘制，高分屏/缩放显示下依然清晰。

【找不到托盘图标？】
  点击任务栏右下角的 ^ 展开隐藏的图标，即可找到本程序的扬声器图标；
  可以把它直接拖到任务栏上固定显示。首次启动时会弹出通知提示。

【注意】
  - 本程序未签名，首次运行如遇 SmartScreen 提示，请点「更多信息」→「仍要运行」。
  - 无需管理员权限；Windows 10 自带的 .NET Framework 4.8 即可运行。
  - 只显示当前处于“活动”状态的设备；蓝牙耳机未连接时不会出现。
  - 退出请用右键菜单「退出」，或结束任务栏中的程序进程。
  - 日志文件：%LOCALAPPDATA%\AudioSwitch\AudioSwitch.log
  - 更完整的项目说明/检查总结见 README.md、PROJECT_SUMMARY.md。
